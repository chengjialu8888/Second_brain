# Open Questions

> Questions that would make future Second Brain answers more useful if a human answered them.

## Highest Leverage Questions

- [ ] What subjective context is missing from the latest diary drafts?
- [ ] Which current project pages need clearer goals or success metrics?
- [ ] Which people pages contain inferred claims that should be confirmed or softened?

## By Domain

### People

- [ ] Add relationship context, communication preferences, and confidence level for important people pages.

### Projects

- [ ] Confirm which active projects deserve weekly review.

### Concepts

- [ ] Identify concepts that are currently useful but undersourced.

### Diary

- [ ] Review draft diary entries and add "what it meant", not only "what happened".

## Agent Maintenance Rules

- Add questions here when search, lint, ingestion, or diary drafting exposes missing context.
- Prefer questions a human can answer directly.
- When a question is answered, move the resulting insight into the relevant canonical page and add a dated Timeline entry there.
- Do not delete resolved questions silently; move them to the archive section with the resolution link.
