# Review Queue

> Claims, summaries, and page changes that should be reviewed by a human before being treated as durable Compiled Truth.

## Needs Human Confirmation

- [ ] New agent-written conclusions that affect personal strategy, commitments, or relationships.
- [ ] Low-confidence inferences that were useful enough to write down but not certain enough to trust.
- [ ] Diary drafts generated from calendar data without subjective context.

## Safe To Merge After Review

- [ ] Clean source-backed facts with dates and stable source refs.
- [ ] Minor page organization improvements that preserve meaning.
- [ ] Broken-link fixes where the target is obvious.

## Do Not Auto-Merge

- Private or sensitive raw sources.
- Claims about people without enough identifying context.
- Strategic recommendations that lack source refs or confidence labels.
- Anything that rewrites user-authored ideas without explicit approval.

## Agent Maintenance Rules

- Add an item here when a claim belongs in Compiled Truth only after user confirmation.
- Include the candidate target page and a short reason.
- After review, move accepted claims into the canonical page and add Timeline evidence.
- If rejected, note the rejection here or in the relevant page's Timeline.
