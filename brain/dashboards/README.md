# Dashboards

Agent-maintained dashboards for human review in Obsidian.

Start with:

- [[home]]: vault home and review cockpit
- [[open-questions]]: unresolved questions and missing context
- [[review-queue]]: claims and changes that need human judgment
- [[recent-changes]]: dated change feed across sources, entities, and outputs

These pages are not raw memory. They are navigation surfaces that help humans decide what to inspect, confirm, or improve next.
