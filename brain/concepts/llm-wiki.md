# LLM Wiki

> A persistent, compounding Markdown layer maintained by an LLM between raw sources and user queries.

## Definition

LLM Wiki moves work from query time to write time. Instead of re-reading raw sources for every question, the agent updates cross-linked pages as new sources arrive.

## Why It Matters

The wiki becomes an asset humans can browse and agents can load progressively.

## My Current Read

For a personal Second Brain, LLM Wiki is the right first storage pattern because it is file-based, inspectable, and easy to evolve into a structured brain layer later.

## Counterexamples / Risks

Markdown without resolver rules can rot quickly. The system needs lint, templates, source refs, and duplicate detection.
