# People Resolver

Use `people/` for human beings with relationship, interaction, or future value.

Before creating a person page:

1. Search exact name.
2. Search aliases and likely variants.
3. Check whether the person is only a one-off mention with no context.
4. If the person matters, create a page using `brain/schema.md`.

Do not create people pages from random guest lists or unsupported single-name mentions.
